# Turbo Downloader TM

Gerenciador de downloads para **Windows 10/11**, desenvolvido por **Talison Maurer**. Interface em português brasileiro.

## Download oficial — Microsoft Store

[**⬇️ Abrir o Turbo Downloader TM na Microsoft Store**](https://apps.microsoft.com/detail/9NFHZMVLN66D)

> **Publicação em andamento:** o aplicativo foi enviado para certificação em 10/11/2026. A instalação pela Microsoft Store ficará disponível após a aprovação e publicação. Até lá, o link pode não oferecer a opção de instalar.

**Alternativa temporária:** [Baixar o executável portátil (.exe) pelo GitHub Releases](https://github.com/talisonmaurer/TurboDownloader-Releases/releases/latest). Essa versão não tem assinatura digital verificada e pode ser bloqueada pelas proteções do Windows.

## Funcionalidades

- **Downloads por URL** HTTP/HTTPS com até **32 conexões simultâneas**, quando suportadas pelo servidor.
- **Progresso, velocidade e tempo restante estimado** em tempo real.
- **Nome personalizado** e escolha da pasta de destino.
- **Pausa e retomada** quando o servidor aceita requisições por intervalo.
- **Modo captura opcional**: identifica links HTTP/HTTPS copiados para a área de transferência.
- **Interface gráfica em português brasileiro**.

## Como instalar

1. Abra a [página do Turbo Downloader TM na Microsoft Store](https://apps.microsoft.com/detail/9NFHZMVLN66D).
2. Após a publicação, selecione **Instalar**.
3. Abra o programa pelo menu Iniciar do Windows.

## Observações

- A velocidade depende da sua conexão e do servidor; mais conexões nem sempre significam maior velocidade.
- A captura monitora apenas links copiados quando ativada; não intercepta automaticamente downloads do Chrome ou Edge.
- Baixe apenas arquivos para os quais você tenha autorização.
- Consulte nossa [Política de Privacidade](PRIVACIDADE.md).
