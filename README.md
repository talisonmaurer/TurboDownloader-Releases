# Turbo Downloader

Gerenciador de downloads para **Windows 10/11**, desenvolvido para facilitar o download de arquivos por links diretos.

[**⬇️ Baixar a versão mais recente (.exe)**](https://github.com/talisonmaurer/TurboDownloader-Releases/releases/latest)

## Funcionalidades

- **Downloads por URL** com até **32 conexões simultâneas**, quando suportadas pelo servidor.
- **Progresso, velocidade e tempo restante estimado** durante o download.
- **Nome personalizado** para salvar o arquivo.
- **Pausa e retomada** nos casos em que o servidor permite downloads por intervalos.
- **Modo captura opcional**: identifica links HTTP/HTTPS copiados para a área de transferência.
- **Interface gráfica**, sem janela de console ao executar o programa compilado.

## Instalação

1. Abra a [página de versões](https://github.com/talisonmaurer/TurboDownloader-Releases/releases/latest).
2. Em **Assets**, baixe o arquivo `TurboDownloader.exe`.
3. Execute o programa no Windows.

> O aplicativo é distribuído como executável portátil. Para downloads, utilize links e conteúdos que você tem autorização para baixar.

## Observações

- A velocidade depende da sua conexão e dos limites impostos pelo servidor. Usar mais conexões nem sempre acelera o download.
- O modo captura monitora **links copiados**; não intercepta automaticamente os downloads do Chrome ou Edge.
- Se o Windows exibir um aviso de segurança para um aplicativo não assinado, confira a origem do arquivo antes de executá-lo.
